# The definition of a task

Four lines. Write them before the agent starts, and paste them at the top of the request.

1. **What I need**, in one sentence.
2. **Who it is for.**
3. **The limits**, such as budget, time and what must not change.
4. **How we will know that the result is good.**

## Example

1. I need the export to include tasks that have attachments.
2. It is for people who move their lists to another app.
3. No new dependencies. The existing export files must keep their format.
4. A list with three attachments exports, and the test suite stays green.
